# src

Pasta principal dos arquivos do site InovaJK.

Aqui ficam as páginas, estilos, scripts, recursos visuais e pastas reservadas para componentes e serviços.

## Estrutura

- `pages/`: páginas HTML do site.
- `styles/`: estilos CSS.
- `controllers/`: scripts JavaScript de interação e validação.
- `components/`: componentes reutilizáveis.
- `services/`: serviços e integrações.
- `assets/`: imagens, ícones e fontes.
