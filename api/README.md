# API

Pasta responsável pela API do projeto InovaJK.

O backend está estruturado como uma aplicação Spring Boot com Maven. Atualmente, a aplicação possui a classe principal, configuração básica e dependências para Web, JPA, Security e MySQL.

## Principais arquivos

- `pom.xml`: dependências e configuração do projeto Maven.
- `src/`: código da aplicação, configurações e testes.
- `mvnw` / `mvnw.cmd`: scripts do Maven Wrapper.

A API é separada do site estático e concentra a parte de backend do projeto.
